# Vacation Club Portfolio Map

An interactive map displaying Marriott and Hyatt Vacation Club resort locations across the USA and internationally.

## Features

- Interactive Leaflet.js map with resort markers
- Search functionality for resorts by name or address
- Filter by brand (Marriott or Hyatt)
- Click on resorts to zoom and view details
- Responsive design for mobile and desktop
- Google Maps directions integration

## Tech Stack

- Next.js 14
- React 18
- Leaflet.js with React-Leaflet
- Tailwind CSS
- TypeScript

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Deployment

This app is configured for deployment on Vercel. Simply connect the repository to Vercel for automatic deployments.
